# Echoes of the Hollow Sun

A dark-fantasy 2D side-scrolling Action RPG (Metroidvania) built in pure Python with Pygame and procedural NumPy audio synthesis.

## Story Synopsis
In the subterranean kingdom of **Heliosthome**, the Sun-King Aurelius bound a dying star within the **Obsidian Pelorus** to halt the creeping frost. Instead, time fractured: the citizenry withered into ash husks, and unfulfilled memories manifested as hostile wraiths. You awaken as **Vesper**, a silent Vessel-Scribe wielding the **Cinderblade**, able to harvest **Echoes** and **Lumen** to uncover the truth behind the Hollow Sun.
